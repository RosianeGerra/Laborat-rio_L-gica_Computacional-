# Laboratório de Lógica Computacional

Projeto desenvolvido durante meus estudos de Lógica para Computação no Bacharelado em Sistemas de Informação.

## Conteúdos estudados

- Proposições lógicas
- Valores lógicos
- Conectivos lógicos
- Tabelas-verdade
- Tautologia
- Contradição
- Contingência
- Implicação lógica
- Equivalência lógica
- Álgebra das proposições

## Objetivo

Registrar e aplicar, de forma prática, os conhecimentos adquiridos
na disciplina de Lógica para Computação.

## Evolução

Este projeto será atualizado conforme novos conteúdos forem estudados
e posteriormente receberá implementações em código.
